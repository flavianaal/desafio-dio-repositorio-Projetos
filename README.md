# 🚀 Desafio DIO - Projetos e Exercícios

Repositório criado durante os estudos na **DIO (Digital Innovation One)** para reunir desafios, exercícios e práticas de programação.

## 📌 Sobre o projeto

O repositório reúne diferentes atividades desenvolvidas durante o curso, com foco na prática de conceitos de **JavaScript e lógica de programação**.

Entre os exercícios, estão atividades envolvendo funções, estruturas condicionais, classes e conceitos de programação orientada a objetos.

## 📂 Conteúdo

O repositório contém:

* ⚔️ **Heroi.js** — exercício envolvendo criação de classes e diferentes tipos de heróis e ataques.
* 🧮 **calcular.js** — função para calcular o saldo de vitórias e determinar o nível do herói.
* 📝 **desafio03.js** — exercício de programação em JavaScript.
* 🕷️ **homemAranha.js** — exercício desenvolvido durante os estudos.

## 🛠️ Tecnologias

* JavaScript
* Git

## 🎯 Objetivo

Praticar fundamentos de programação e desenvolver conhecimentos em JavaScript por meio dos desafios e exercícios propostos durante os estudos na DIO.

## 📚 Conceitos praticados

* Git e GitHub
